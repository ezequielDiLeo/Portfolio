Proyecto insignia Producción / Demo

FormFlow

Constructor visual dinámico de formularios web con canvas interactivo, editor de propiedades en tiempo real y vista previa de landing page.

Problema

Necesitaba una edición fluida de estructuras dinámicas sin acoplar el canvas, la configuración y la vista previa a una lógica compartida difícil de evolucionar.

Arquitectura y decisiones técnicas

Desacoplé el estado del formulario del renderizado del canvas mediante Angular Signals: las mutaciones actualizan el esquema serializable y los consumidores derivados responden solo a los cambios relevantes. La serialización dinámica permite reconstruir campos, propiedades y vista previa sin re-renders innecesarios ni dependencia de una interfaz rígida.

Proyecto full-stack Arquitectura REST

Plataforma de Telemetría & API REST

Sistema full-stack para ingesta, almacenamiento y visualización de métricas de servidores en tiempo real.

Problema

Consolidar métricas distribuidas con validaciones consistentes y una interfaz reactiva capaz de representar cambios sin acoplar UI y persistencia.

Arquitectura y decisiones técnicas

Backend desacoplado en NestJS con Prisma ORM sobre PostgreSQL. DTOs estrictos validan los eventos de ingesta y endpoints RESTful separan contratos de dominio de presentación. Angular consume la API y actualiza el dashboard reactivo con estados derivados y fuentes de datos claras.
